Your workout says five sets of five deadlifts, two minutes rest. The sets are not timed — a set of five takes as long as it takes, twenty seconds on a good day, forty when the bar is slow off the floor. What you want is simple: finish the set, tap once, let the rest count itself down, and have something keep track of which set you are on.

That turns out to be an awkward thing to ask of most timers. A stopwatch counts up and forgets the set number. An interval timer counts the sets but insists on timing the work too, so it rolls into rest while you are still mid-rep. The set counter is the easy half. The hard half is a timer that waits for you.

## Why fixed work intervals break strength sets

Interval timers were built for HIIT, where the clock is the workout: 40 seconds of burpees ends at 40 seconds whether you did 12 or 15. Strength sets work the other way round. The reps are fixed and the time is whatever it is, so any fixed work interval is wrong in one direction or the other.

Set it too short and the rest starts while you are still lifting, which means your two minutes is really a minute and a half. Set it too long and you stand around waiting for the timer to catch up, which quietly turns two minutes of rest into two and a half. Either way the session stops being repeatable — the exact problem a timer was supposed to solve.

What you actually need has three parts. A work phase that ends when you say so, a rest phase that runs on its own clock, and a counter that knows when the last set is done so the workout ends instead of looping.

## The setup: a generous work cap and a skip

The cleanest way to get this from an interval timer is to stop treating the work time as a target and start treating it as a ceiling. Set the work phase to longer than any set could take — 90 seconds for most sets of five, up to three minutes for long sets or carries — and the rest to exactly what your programme says. Set the round count to your number of sets.

Then, when the set is done, skip forward. The timer drops straight into rest, counts it down, cues you at the end, and moves the counter to the next set. After the last set it finishes rather than starting a sixth. If a set ever runs past the cap, the rest just starts on its own — a useful nudge that the set has gone on too long.

In Peak Interval that is one exercise with a work length, a rest length and a round count, and skipping ahead from the work phase starts that set's rest immediately. A 3-second countdown into each new set tells you to get your grip and brace before you need to, and the set number stays on screen so you never have to remember whether that was set three or four.

## Where your hands are when the set ends

The reason this setup feels clumsy in most apps is that the skip button lives on the phone, and the phone is on the floor. Bending down after a heavy set to unlock it and find the button is exactly the kind of friction that makes people give up and go back to guessing.

In Peak Interval the skip control also sits on the lock-screen Live Activity, so it is one tap on the screen without unlocking, and the phone can stay propped against a plate. The Apple Watch app gives you a haptic tap at the end of each rest and lets you pause or step back a phase from your wrist. To be straight about the current limit: advancing to the next phase from the Watch is not there yet, so the tap that ends a set happens on the phone's lock screen. If wrist-only control matters most to you, that is worth knowing before you build the habit.

## Mixing hand-timed sets with timed work

Plenty of sessions combine both kinds of set. Heavy squats on a manual skip, then accessory work on a fixed 40/20, then a timed carry to finish. You do not need two apps for that. Build the strength block with long work caps and its own rest, follow it with the timed block, and let the [round structure](/blog/posts/interval-timer-repeating-sets) carry you from one to the other.

The rest lengths are where most of the thinking goes, and they deserve it — three to five minutes for heavy triples, ninety seconds for hypertrophy sets. [How long to rest between sets](/blog/posts/rest-timer-between-sets) covers that side. This post is only about the mechanics of getting a timer to wait for you.

## The short version

If your sets end when the reps are done, set the work interval as a ceiling rather than a target, set the rest to your programmed number, and set the rounds to your set count. Skip forward the moment you rack the bar and let the timer handle the rest and the counting. You stop guessing which set you are on, the rest stays the length you planned, and the workout ends on the last set instead of whenever you remember to check.
